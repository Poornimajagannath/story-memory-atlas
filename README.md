# Story Memory Atlas

Beautiful, offline-friendly HTML guides for remembering stories.

This repository contains:

- `skills/story-memory-atlas/` — a reusable Codex skill for creating story memory atlases.
- `templates/atlas-template.html` — a visual starting point.
- `examples/odyssey-memory-atlas.html` — an epic and mythology example.
- `examples/project-hail-mary-memory-atlas.html` — a science-fiction example.

Open either HTML file directly in a browser. No build step is required.

The guides use original summaries and analysis. They do not reproduce source books, scripts, or protected ebook text.
